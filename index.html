02

Prediksi Harga Emas

Mini Project · Study Group I-SMILE · Juara 3 · Tim 2 orang

Memprediksi harga emas dari indikator makroekonomi: harga perak, platinum, minyak, Indeks Dollar AS, S&P 500, dan saham GDX. Model Random Forest dibandingkan dengan Linear Regression lewat 5-fold cross validation, dan mencapai R² 0,993 dengan MAE sekitar $0,98. Peran saya: analisis data, EDA, dan preprocessing.

  • Python
  • scikit-learn
  • Random Forest
  • EDA
  • Regresi

03

Klasifikasi Cacat Pelat Baja

Proyek Machine Learning · Klasifikasi multi-kelas

Mengklasifikasikan tujuh jenis cacat pada pelat baja dari data fitur fisik. Datanya tidak seimbang dan banyak outlier, jadi KNN (72,8%) dibandingkan dengan Random Forest yang lebih tahan terhadap keduanya dan mencapai akurasi 80,2% pada data uji.

  • Python
  • scikit-learn
  • KNN
  • Random Forest
  • Data Imbalance

AgriMonitor

Aplikasi web · Dashboard pemantauan lahan

Dashboard untuk mencatat suhu, kelembapan, dan pH tanah. Setiap data baru langsung diberi status Normal, Perlu Perhatian, atau Kritis, lalu ditampilkan dalam tabel dan grafik. Dibangun dengan Flask dan dikemas dengan Docker.
