02

Prediksi Harga Emas

Mini Project · Study Group I-SMILE · Juara 3 · Tim 2 orang

Memprediksi harga emas dari indikator makroekonomi: harga perak, platinum, minyak, Indeks Dollar AS, S&P 500, dan saham GDX. Model Random Forest dibandingkan dengan Linear Regression lewat 5-fold cross validation, dan mencapai R² 0,993 dengan MAE sekitar $0,98. Peran saya: analisis data, EDA, dan preprocessing.

Tentang

Deftrian Dwi Wicaksana merupakan mahasiswa S1 Teknik Komputer di Telkom University, Bandung, angkatan 2024. Memiliki ketertarikan pada perkembangan teknologi, khususnya Machine Learning, Internet of Things (IoT), dan Cyber Security. Senang mempelajari hal-hal baru, mengeksplorasi ide, serta mengembangkan kemampuan di bidang teknologi dan kepemimpinan.

Memiliki pengalaman dalam memimpin dan mengelola berbagai kegiatan organisasi maupun kepanitiaan, di antaranya sebagai Ketua Pelaksana Compile Tech Fest 2026 dan Ketua Divisi Acara CENTURION 2026. Di bidang akademik, berhasil meraih juara 3 dalam kompetisi I-SMILE Mini Project Machine Learning serta aktif mengembangkan keterampilan teknis melalui berbagai proyek dan kegiatan pembelajaran. Pengalaman tersebut membentuk kemampuan dalam leadership, teamwork, problem solving, dan project management.
